分组范围

限定哪些 AIHub 分组参与路由；点选后由插件固定在这些组里选路，不再新建 Key。

打开「监控」页加载一次分组

打开「监控」页加载一次分组后，这里会列出可点选的分组。

开启后插件会在你的 AIHub 账户里新建专用密钥；服务端配额限制尚未验证，不能据此保证费用上限。插件不会删除密钥，关闭开关也不会撤销已创建的密钥。

同名模型在多个平台都存在时，路由按请求头提示与分组公布清单推断平台；推断不出来时 503 文案会列出各平台的命中数。

Key 与余额保护

限制自动创建的范围，并按账户余额暂停建 Key。

模型与协议

确定对外暴露哪些平台与模型。

页面服务

监控与设置由本插件自己的只读回环服务提供。

服务只监听回环地址，页面经 Magpie 的插件服务入口访问；在 magpie web 下浏览器会由 Magpie 代理转发，无需额外开放端口。端口被占用时页面会显示宿主的重试提示，换一个端口即可。

运行方式 会话亲和只保存在插件进程内存里，宿主重载后重置；保存选项可能触发宿主重载。

供应商 aihub-auto。六平台故障转移保持同一平台与模型；监控只读。

存储设置只保存在此插件的非敏感选项里；底部保存条只在有未保存改动时出现。
